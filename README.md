# Lihu Xu personal homepage

A lightweight, plain academic homepage ready for GitHub Pages.

## Publish with GitHub Pages

1. Create a GitHub repository called `YOUR-USERNAME.github.io`.
2. Upload these files to the repository root and commit them.
3. In the repository, open **Settings → Pages** and select **Deploy from a branch**, using `main` and `/ (root)`.
4. Visit `https://YOUR-USERNAME.github.io` after the deployment completes.

Before publishing, replace `YOUR-USERNAME` as appropriate and add any verified links you would like to display, such as Google Scholar, ORCID, or a downloadable CV.
